openbox shortcut cheatsheets

A-Escape faster to switch windows (not including minimized windows)
A-Tab = used to switch windows (including minimized)

W-S-Right/Left/etc (DirectionalCycleWindows) + basically A-Escape with UI like A-Tab controlled with arrow key (not including minimized windows)

#cheatsheets
Window + plus = enable/disable fullscreen
Window + minus = hide/unhide all window (show desktop)
Window + Ctrl + plus = Un/Maximize
Window + Ctrl + minus = Iconify
Ctrl + Alt + left arrow = go to desktop left
Ctrl + Alt + right arrow = go to desktop right
Shift + Alt + left arrow = send window to desktop left
Shift + Alt + right arrow = send window to desktop right
Window + F1 = go to desktop 1
Window + F2 = go to desktop 2
Window + F3 = go to desktop 3
Window + F4 = go to desktop 4

Window + Ctrl + right arrow = increase window size to right
Window + Ctrl + left arrow = increase window size to left
Window + Ctrl + up arrow = increase window size upwards
Window + Ctrl + down arrow = increase window size downwards

Window + Alt + right arrow = decrease window size to right
Window + Alt + left arrow = decrease window size to left
Window + Alt + up arrow = decrease window size upwards
Window + Alt + down arrow = decrease window size downwards

Alt + F4 = close window
Alt + Escape = switch window
Alt + Space = show client (window) menu
Window + Space = show root menu
Window + Tab = show client list menu (desktop list)

Alt - Tab = show window list (switch window)
Window + Shift + right arrow = switch focus window to right
Window + Shift + left arrow = switch focus window to left
Window + Shift + up arrow = switch focus window up
Window + Shift + down arrow = switch focus window down

Fn + F1 = mute/unmute audio
Fn + F2 = decrese audio volume
Fn + F3 = increase audio volume
Fn + F4 = mute/unmute mic
Fn + F5 = decrease brightness
Fn + F6 = increase brightness

Window + Enter = terminal (urxvt)
Window + 

Window + left arrow = move floating window to left
Window + right arrow = move floating window to right
Window + up arrow = move floating window upwards
Window + down arrow = move floating window downwards

Print = screenshot full display
Alt + Print = screenshot partial
